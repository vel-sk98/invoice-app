# 🚀 Invoice app - Invoo

---

A full-featured invoice management app built with React + Vite.
Designed from Figma and built from scratch.

## ✨ Features

- Create, edit, delete, and manage invoices effortlessly.

- Filter invoices by status: **Draft**, **Pending**, **Paid**.

- Data is stored using `localStorage` - no data loss on refresh.

- Inline form validation to prevent errors before submission.

- Seamless theme switching with system preference support.

- Optimized for mobile, tablet, and desktop.

---

## 🛠 Tech Stack

| Category | Technology |
|--------|------------|
| Frontend | React 18 |
| Build Tool | Vite |
| Routing | TanStack Router |
| Styling | CSS (Flexbox + Grid + Variables) |
| State | React State + LocalStorage |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/vel-sk98/invoice-app.git

# Navigate into the project
cd invoice-app

# Install dependencies
npm install

# Start the development server
npm run dev
```
